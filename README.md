## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Preset Library** | Organize Trem Control presets by modulation style and speed |
| **Shape Notes** | Document modulation waveform and shape settings per preset |
| **Rate Config** | Track tempo-sync and free-running rate settings per preset |
| **Style Tags** | Tag tremolo presets by genre and guitar or synth application |
